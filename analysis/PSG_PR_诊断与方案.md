# PSG 的 PR 误差与下一版方案

目标是按当前 ECG 参考和旧偏移搜索规则，把每条 PSG 的 RMSE 等权平均降至 3 bpm。另报所有有效秒合并的 RMSE。下文将 Excel 正式回放、日志实验和待验证的算法分开。

## 正式回放与日志实验

工作簿中 23 条 PSG 共有 602,620 个共同有效秒。Current、A、B、C 的逐记录平均为 3.4715、3.4655、3.4694、3.6123，合并 RMSE 为 3.6636、3.6572、3.6604、3.8002。假设事后对每一夜挑四者中最好的一个，等权平均也只有 3.4564。误差最高的七条为 45、11、25、30、16、42、10。

诊断脚本从两套已有 MATLAB 分阶段日志的 fixed PR 重建当前长短历史各占一半的回退，再计算最近 10 个输出的中位数和取整。使用正式回放的逐记录偏移。连续历史不全的暖机点被排除，日志与 C 也有数值差异。23 条重建记录有 602,475 个评价秒，等权 3.4671，合并 3.6615。以下模型都只和这条基线在同一批秒上比较。

### 保留中间测量值有多少收益

学习目标是逐秒的 ECG HR 减当前输出。推断只使用光电算法产生的数值、置信度和体动。按 PSG 编号五折留出，每条记录只在其他编号上训练的模型上预测一次。训练集每五行抽一行，各训练受试者总权重相同。固定 100 次梯度提升、每棵树最多 15 个叶节点。没有用测试人的 ECG 训练校正器，但离线算分沿用整夜 Current 与 ECG 之间估计的偏移。若有同一人多晚，后续应按真实人员标识分组。

### 哪些秒值得先看

下表是 602,475 个日志评价秒的分层。各行重叠，平方误差占比是合并口径。

| 条件 | 秒数占比 | 平方误差占比 |
|---|---:|---:|
| 当前绝对误差 ≥10 bpm | 2.7% | 49.8% |
| 当秒 confidenceG ≤0.35 | 11.4% | 32.7% |
| 当秒 confidenceG ≥0.55 | 86.2% | 61.7% |
| Movement >15 | 5.2% | 15.9% |
| ECG 在 t−2 到 t+2 秒相差 ≥5 bpm | 14.0% | 34.1% |

若仅把目前 ≥10 bpm 的那些秒的平方误差减半，其他秒完全不变，重算逐记录平均为 3.033。这是目标量级的反事实估算。另一次诊断要求 ECG 中心五秒均有效，在同一批 592,861 秒上，当前输出相对逐秒 ECG 为 3.360，相对中心五秒均值为 2.867。这量化了参考时间尺度的影响，产品目标仍是原逐秒 ECG。

## 建议的实验顺序

1. 把因果后处理结果作为下一版对照。对每秒保留 raw PR、用于回退的 fixed PR、最终 PR、confidenceG、距上次可靠更新的时间、独立新峰数、体动。优先看 45、42 的改善来自哪些片段，以及 14、18、40 怎样回退。校正结果超过约定的可信范围时保留 Current 作为可比较的回退输出。
2. 三通道各自生成脉搏候选。按连续段先去趋势和滤波，分别计算峰间距、形态和周期性。用约 4–6 秒追变化、约 10–16 秒判断稳定周期。保留几个候选与质量，在各通道之间按候选证据融合；共模体动可以同时污染多个通道。先测大误差秒上，候选集合中是否出现接近 ECG 的值，再测只依赖 PPG 的选择器能否选对。设备输出全程采用独立于 ECG 的选择器。
3. 若候选覆盖够好，可把 PR 及变化速度当作隐藏状态，用动态规划或概率滤波连续解码。稳定段偏好连续，多个新峰支持加速或减速时可快速切换，低质量长期保持须有时限。分别测实时版、固定延迟版和整夜离线版。若进入学习波形的阶段，可用多尺度一维卷积学习逐秒 PR 候选分布，以传统候选和当前估计作为对照。
4. 独立审查采集时钟和 ECG 参考。PPG 包按计数分段，段内时间由首末接收时间线性插值得到，Movement 却以原接收时间配对。检查有效采样率、断点、分段重置、伪迹和 ECG R 峰。对 10、11、14 重点审查偏移和独立同步锚点。对 16、25、45 重点看原始 ECG 与三路光电，分开统计稳定、快速变化、运动、低灌注、呼吸事件或觉醒附近时段，有标注再分层。
5. 固定参考、偏移、配对秒与覆盖要求。以人员为单位隔离训练、调参和确认数据，并监测合并 RMSE、大误差比例、连续错误时长、覆盖率和输出延迟。逐秒最接近 ECG 的通道、局部重新对齐或参考平滑只作为诊断，单独报告。下一次正式比较应直接重放原始波形并使用未参与选方案的整夜记录。
